# Budget Manager - React Query

Version React de l'application de gestion de budget utilisant TypeScript, Vite et TanStack React Query pour les donnees distantes.

## Demarrage

Prerequis : Node.js et npm.

```bash
npm install
npm run dev
```

Ouvrez l'adresse affichee par Vite dans votre navigateur.

## Commandes

```bash
npm run dev      # serveur de developpement
npm run build    # build de production
npm run lint     # verification du code
npm run preview  # apercu du build
```
