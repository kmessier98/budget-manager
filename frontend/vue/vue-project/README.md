# Budget Manager - Vue

Version Vue de l'application de gestion de budget. Elle utilise Vue 3, TypeScript, Vite, Pinia et PrimeVue.

## Demarrage

Prerequis : Node.js et npm.

```bash
npm install
npm run dev
```

Ouvrez l'adresse affichee par Vite dans votre navigateur.

## Commandes

```bash
npm run dev         # serveur de developpement
npm run build       # verification des types et build de production
npm run type-check  # verification des types
npm run preview     # apercu du build
```
