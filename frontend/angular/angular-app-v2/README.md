# Budget Manager - Angular V2

Deuxieme version de l'application de gestion de budget, developpee avec Angular, PrimeNG et Bootstrap.

## Demarrage

Prerequis : Node.js et npm.

```bash
npm install
npm start
```

Ouvrez l'adresse indiquee par Angular dans votre navigateur.

## Commandes

```bash
npm start       # serveur de developpement
npm run build   # build de production
npm test        # tests unitaires
```
